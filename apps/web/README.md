# RideSync — Student Web App

The student-facing tracking site for **RideSync**. Enter a driver's short code and watch the live bus on a map with per-stop ETAs.

Built with Next.js (App Router) + Leaflet, subscribing to Supabase Realtime.

👉 **See the [root README](../../README.md) for the full project overview, architecture, and setup.**

## Run locally

```bash
cp .env.example .env.local   # add your Supabase URL + anon key
npm install
npm run dev                  # → http://localhost:3000
```
